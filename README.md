## 🛡️ [SecureGuard](https://github.com/Rupa-2006/Personal-Digital-Security-Posture-Analyzer) — personal security posture analyzer

A browser-based tool that checks passwords against **real data breaches** (Have I Been Pwned, using k-anonymity so the password never leaves the browser),
detects password reuse with HMAC fingerprints, flags phishing links (look-alike domains, brand impersonation), and builds a security score and PDF report.
Deployed with a strict Content Security Policy and unit-tested.

**[▶ Live demo](https://personal-digital-security-analyzer.netlify.app)** · **[Source code](https://github.com/Rupa-2006/Personal-Digital-Security-Posture-Analyzer)**
